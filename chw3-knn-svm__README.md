# CHW3 · KNN and SVM

[KNN assignment](assignment-knn.pdf) · [KNN notebook](knn.ipynb) · [SVM assignment](assignment-svm.pdf) · [SVM notebook](svm.ipynb)

The KNN notebook uses Iris to explore nearest-neighbor predictions. The SVM notebook uses synthetic moons and circles to examine decision boundaries. Both use datasets supplied or generated by scikit-learn.

## Assignment brief in English

Implement KNN on Iris with manual distances and majority voting. Compare values of k, distance metrics, and the course's scikit-learn reference. For SVM, compare kernels on synthetic datasets and analyze how the regularization parameter C affects the linear margin.

## How I solved it

The KNN notebook evaluates k = 1, 3, 5, 7, and 11, compares Euclidean, Manhattan, and Minkowski distances, and checks the custom classifier against KNeighborsRegressor, as specified in the brief. The SVM notebook fits linear, polynomial, and RBF models, reports test accuracy, and plots decision boundaries, support vectors, and margins.
