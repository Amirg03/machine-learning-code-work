# Machine Learning Code Work

Five Jupyter coursework exercises, from implementing regression models to comparing classifiers and visualizing principal components. Each folder includes the original Persian assignment, an English summary of its requirements, and an explanation of the solution with links to the notebooks. The notebooks retain their saved outputs.

| Exercise | Assignment and implementation |
| --- | --- |
| [CHW1 · Linear regression](chw1-linear-regression/) | Predict housing prices, scale features, and examine a custom linear regression implementation. |
| [CHW2 · Logistic regression](chw2-logistic-regression/) | Build binary logistic regression and compare it with scikit-learn on the supplied COVID survey dataset. |
| [CHW3 · KNN and SVM](chw3-knn-svm/) | Explore KNN with the Iris dataset and compare SVM behavior on synthetic decision boundaries. Includes separate briefs and notebooks. |
| [CHW4 · PCA](chw4-pca/) | Implement PCA and K-means, compare PCA with scikit-learn, and explore image compression and clustering on Iris. |
| [CHW5 · Tree ensembles](chw5-tree-ensembles/) | On the Cryotherapy dataset, vary tree depth and compare Decision Tree, Random Forest, and AdaBoost using metrics and plots. |

## Open the notebooks

Install dependencies with `python -m pip install -r requirements.txt`, then run `jupyter notebook` from the repository root. Open each notebook in its exercise folder so relative paths resolve. See the folder notes for external inputs required by CHW2 and the image section of CHW4. The saved outputs can be read without rerunning the notebooks.

Original assignment PDFs are included as course reference material. This repository collects coursework exercises; the [animal image classification project](https://github.com/Amirg03/animal-image-classification-cnn) is separate.
